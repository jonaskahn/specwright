# Editable implementation vocabulary

scripts/leakage.py reads only entries starting with `- `. Each is a literal phrase matched
case-insensitively at word boundaries. Add domain product, vendor and interface names as
they appear in proposals. This is a review aid, not a classifier. Actors sections are not
scanned; quotes inside Problem and Outcome are, so a quoted solution cannot evade review.
