# medallion

## Best for
Explicit maturity boundaries and refinement stages.

## Not this type
Not a measured CAD model, UI mockup, approval record or executable workflow.

## Layout and budget
Start with assets/medallion-template.html. Keep at most nine parts and twelve
relationships; use full outlines and retain readable names in both themes.
These illustrations are hand-authored, not JSON-engine output. Do not invent
spatial relationships or maturity claims to fill empty space.

## Template procedure
Copy the shipped template to an explicitly approved FEAT-NNN-medallion.html path.
Edit only the illustration, title, description, visible source chips and Spec links.
Labels are untrusted data: escape them; never paste markup from a source.
Do not generate or download runtime code. No JavaScript, fonts or remote images.
For a standalone SVG, preserve the SVG title, description, namespace, stylesheet,
background and all traceability text when extracting the one svg element.

## Anti-patterns
Do not treat oblique area as quantity, infer chronology from depth, or imply human
approval from a layer name. Do not hide missing evidence with decorative shapes.
Run the loaded skill's scripts/check_offline.py and scripts/check_borders.py on
both HTML and SVG. Inspect light/dark, reduced-motion, print and small viewports.
