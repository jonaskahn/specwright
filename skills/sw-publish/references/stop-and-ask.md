# Resolve gaps without guessing

Read relevant artifacts before asking. Cite what you checked. Ask only about a
real gap, conflict or preference that the artifacts cannot settle. Record answers in
question and decision records so the next session does not ask again.

Ask at most five questions at once. Use this shape:

> Q1 [blocking] Which refund window applies? Checked SRC-0001 and SRC-0002.
> A) 14 days → the policy source needs amendment.
> B) 30 days → the refund tiers need revision.
> Default if unanswered: leave Q-001 open; publication stays blocked.

Separate blocking decisions from assumptions that can be tested later. Never invent
approval or choose a project scope for an external write just to keep moving.
