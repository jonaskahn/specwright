# Editable implementation vocabulary

The scanner reads only list entries beginning with a dash and a space. Each is a
literal phrase matched case-insensitively at word boundaries. Add domain-specific
product, vendor and interface names when they appear in proposals. This is a review
aid, not a complete classifier. Current-tool references in Actors are not scanned.
Problem and Outcome quotes are scanned too, so a quoted solution cannot evade review.
